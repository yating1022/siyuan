# 👋 你好，世界

欢迎来到 **Fruits Blog**！

这里将记录我在 AI 学习之路上的笔记与心得，也希望能成为一块属于我自己的小天地。

## 📝 如何发布新文章

本站基于 VitePress 构建，写文章非常简单：

1. 在 `docs/src/Notes/` 目录下新建一个 Markdown 文件（可以建子目录分类）。
2. 在文件头部用 `---` 填写元信息：

```markdown
---
title: "文章标题"
desc: "文章摘要，会显示在首页卡片上"
tags: "分类标签，用 / 分隔多个"
updateTime: "2026-08-13 12:00"
---

正文内容……
```

3. 保存后页面会自动热更新，无需手动配置路由。

## 🚀 开启新的旅程

- 想自定义站点外观？修改 `docs/.vitepress/config.mjs`。
- 想添加友链？编辑 `docs/.vitepress/userConfig/friendsInfo.ts`。
- 想展示项目？编辑 `docs/.vitepress/userConfig/projectsInfo.ts`。

那么，开始吧！
